# 时空笔友 · Time Penpal v3.0 ✉️

> 你写一句话给历史，有个**真读过他们自己写的书**的人给你回信。

---

## v3.0 到底升级了什么？

| | v1.0 | v2.0 | **v3.0** |
|---|---|---|---|
| 本质 | 每日推送明信片 | 情绪匹配+人设prompt | **RAG 检索增强生成** |
| 笔友背后 | 无 | prompt里3句人设 | **60条真实史料原文检索** |
| 回信可信度 | AI瞎编 | AI按人设编 | **AI基于真实著作/书信/传记写** |
| 技术栈 | 调API | 调API | **检索器+生成器+Streamlit前端** |
| 简历能写什么 | "调了几个API" | "做了个聊天bot" | **"RAG系统，本地知识库，检索增强生成"** |

## 系统架构

```
用户输入 "考研压力大，怀疑自己"
        ↓
[1] 情绪识别（规则引擎，7类情绪）
        ↓ 命中：焦虑/自我怀疑/目标感/疲惫
[2] 笔友匹配（情绪标签重叠打分）
        ↓ 命中：1977油灯下的知青
[3] RAG 检索（n-gram 重叠，从该笔友6条史料里挑最相关3条）
        ↓ 命中：
        - "白天在地里挣工分，晚上就着一盏煤油灯看书"
        - "那一代人最常说：已经失去过一次，所以不再怕再试一次"
        - "一本《数学》前面缺了30页"
[4] LLM 生成（把史料作为上下文塞进prompt）
        ↓
[5] 输出：一封基于真实史料的回信
```

## 知识库

`knowledge_base.json` 里有 **10位历史笔友 × 每人6条真实史料 = 60条原文**：

1. **1977 知青** — 恢复高考、油灯、缺页课本
2. **苏轼（黄州）** — 《赤壁赋》、东坡肉、《定风波》
3. **李白（赐金放还后）** — 《将进酒》、《行路难》、《独坐敬亭山》
4. **鲁迅（1925北平）** — 《野草》、《两地书》、《热风》
5. **居里夫人** — 四年提炼0.1克镭、拒绝专利、小居里车
6. **梵高（阿尔勒）** — 黄房子、《星月夜》、给提奥的信
7. **杨绛（三里河）** — 《我们仨》、《干校六记》、百岁访谈
8. **萧红（上海）** — 《生死场》、《呼兰河传》、鲁迅序
9. **达尔文（唐恩村）** — 憋了23年才发《物种起源》
10. **三毛（撒哈拉）** — 棺材板做桌子、《送你一匹马》

每条史料都是可溯源的原文摘录，不是AI编的。

## 这玩意儿到底有什么意义？

1. **技术上**：这是一个最小可用的 RAG 系统，面试时能讲清楚"检索器怎么选、prompt 怎么拼、为什么用 n-gram 而不是 embedding（因为没有外部 API 也能跑）"
2. **产品上**：把冷冰冰的"历史冷知识"变成"一个真实的人对你说的话"，有情感价值
3. **内容上**：60 条史料都是真实可溯源的，不是 AI 幻觉——这是 RAG 区别于纯 prompt 的核心
