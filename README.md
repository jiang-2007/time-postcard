# 时空笔友 · Time Postcard v2.0 ✉️

> 你写一句话，历史上的某个人给你写一封回信。

---

## v2.0 升级了什么？

| | v1.0（玩具） | v2.0（产品） |
|---|---|---|
| 方向 | AI 每天单向推一张明信片 | 用户倾诉，历史回信 |
| 核心 | prompt 拼接 | 情绪识别 → 共振匹配 → 角色扮演 |
| 留存理由 | 无（看完就走） | 情感陪伴（像和一个历史上的老朋友写信） |
| 技术栈 | 搜索 + LLM + 文生图 | LLM 情绪分析 + 事件匹配器 + 角色扮演 + 飞书归档 |

## 产品逻辑

```
你写一句话："考研压力好大，怀疑自己"
          ↓
   [Step 1] LLM 情绪识别
   标签 = [焦虑, 自我怀疑, 目标感, 疲惫]
          ↓
   [Step 2] 从 seed_events.json 里挑最共振的事件
   命中 → 1977年恢复高考，油灯下复习的知青
          ↓
   [Step 3] 那个时代的人以第一人称写回信
   "同学：这会儿是1977年12月的一个夜里，油灯噼啪响……"
          ↓
   [Step 4] 自动生成对应年代的插画 prompt
          ↓
   [Step 5] 归档到飞书多维表格（含情绪标签、匹配理由、回信全文）
```

## v2.0 已经上线的种子事件库

`seed_events.json` 里现在有 6 个"历史笔友"：

- **1977 恢复高考** — 回复"跨考/二战/努力是否值得"
- **1802 贝多芬海利根施塔特遗嘱** — 回复"努力没人看见"
- **1910 沈心工在东京** — 回复"跨文化/跨专业从零开始"
- **1943 张爱玲写《倾城之恋》** — 回复"20岁做不被看好的事"
- **1590 莎士比亚在伦敦小剧场** — 回复"非科班、没背景、野路子"

v3.0 计划：用 embedding 向量检索替换规则匹配，把种子库扩到 100+。

## 今天这张 demo

**用户来信**（真实场景）：
> 大二，半工半读做数据标注，跨考复旦应用心理。刚做完一个项目，自己都觉得不够硬，怀疑现在的努力到底有没有意义。

**Agent 匹配**：1977 年冬夜油灯下复习的知青（情绪重叠 4 个）

**回信开头**：
> 同学：这会儿是 1977 年 12 月的一个夜里，油灯噼啪响，我刚从生产队收工回来，棉袄上还沾着土……

完整回信在飞书 Base 里。

## 跑起来

```bash
# 配好 LLM_API_KEY 后：
python main_v2.py --letter "我最近很焦虑，不知道接下来该怎么走"

# 或者进入交互模式，连续写：
python main_v2.py
```
